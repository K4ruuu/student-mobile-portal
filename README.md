# Student Mobile Portal

A standalone student profile component for the Student Mobile Portal Git and GitHub exercise.

## StudentProfile

`StudentProfile.jsx` displays a fictional student's name, student ID, and program.

The component is intentionally standalone and does not require an initialized React application for this exercise.

## Integration example

Import and render the component from a React application:

```jsx
import StudentProfile from "./StudentProfile.jsx";

function App() {
	return <StudentProfile />;
}

export default App;
```
