# Session 10 Reflection

## Why did you use a feature branch?

A feature branch isolates the student profile work from `main` so it can be reviewed before integration.

## How do a commit and a pull request differ?

A commit records a focused snapshot in repository history. A pull request proposes one or more commits for review and integration into another branch.

## What did the reviewer suggest?

The suggested review comment was to add a README example showing where `StudentProfile` should be imported and rendered, or to confirm that the JSX displays correctly when integrated into React.

## How does review improve software quality?

Review provides another perspective on requirements, naming, formatting, tests, and maintainability before changes are merged.
